Wiedergabe
Externe Player

Falls der externe Player gestartet wurde, aber kein Video erscheint, prüfe folgende Punkte:

  • Das gewählte Wiedergabeprofil ist nicht geeignet. Empfohlen wird 'matroska'.
  • Der Streaming-Port (Standard ist 9981) ist nicht korrekt.
  • Der Player kann den Server nicht über den Streaming-Port erreichen. Prüfe, ob der Port im Router oder Proxy korrekt weitergeleitet wird.
  • Der Upload der Daten vom Server ist zu langsam.
Interner Player

Falls der interne Player gestartet wurde, aber kein Video erscheint, prüfe folgende Punkte:

  • Das gewählte Wiedergabeprofil ist nicht geeignet. Empfohlen wird 'htsp'.
  • Der Upload der Daten vom Server ist zu langsam.
Casting
Anforderungen
  • Du benutzt die freigeschaltete Version von TVHClient.
  • Dein Server unterstützt Transcoding.
  • Transcoding, insbesondere VAAPI-hardwaregestütztes Transcoding, funktioniert am besten mit den neuesten instabilen TVH 4.3 Versionen.
Transcoding einrichten

Für maximale Kompatibilität verwende ein Streamprofil mit den folgenden Einstellungen:

  • Container: av-lib/MP4 (Beispiel)
  • Video-Codec: H.264, High profile (Beispiel)
  • Audio-Codec: AAC LC profile (Beispiel)
TVHClient für Casting einrichten
  • Verwende entweder eine IP-Adresse oder einen DNS-Namen für die Verbindung. Vor dem Start des Castings wird der DNS-Name in eine IP-Adresse umgewandelt.
  • Wähle das entsprechende Casting-Wiedergabeprofil aus.
