Playback
External players

If the external player has been started but no video is showing, check the following points:

  • The selected playback profile is not suitable. Recommended is 'matroska'.
  • The streaming port (default is 9981) is not correct.
  • The player cannot reach the server via the streaming port. Check whether the port is properly forwarded by the router or a proxy.
  • Uploading the data from the server takes too long.
Internal player

If the internal player has been started but no video is showing, check the following:

  • The selected playback profile is not suitable. Recommended is 'htsp'.
  • Uploading the data from the server takes too long.
Casting
Requirements
  • You are using the unlocked version of TVHClient.
  • Transcoding support is enabled on your TVHeadend server.
  • Transcoding, especially VAAPI hardware-assisted transcoding, works best on recent unstable TVH 4.3 builds.
Set up transcoding

For maximum compatibility (Casting, most browsers, players and the internal player) use a stream profile with the following settings:

  • Container: av-lib/MP4 (example)
  • Video codec: H.264, High profile (example)
  • Audio codec: AAC LC profile (example)
Set up TVHClient for casting
  • In the connection settings you can use either an IP address or a DNS name for the connection. Before casting is started, the DNS name is converted to an IP address.
  • Select the appropriate casting playback profile.
